# UWP 더피 홈페이지 — 모바일 및 익명 게시판 개선본

## 이번 수정
- 기존 학교 홈페이지, 학사 일정, 가상 포털 및 쪽지 흐름 그대로 유지.
- 포털 **DIVE(가칭)**: 이름 미확정 상태 유지. `MyUWP`는 사용하지 않음.
- 포털 모바일 가로 넘침 대응: 그리드 최소 폭·문구 줄바꿈, 모바일 사이드 메뉴 2~3열 줄바꿈, 입력창 폭 제한.
- 익명 게시판 UI 전체 개편: **인기글 3개 → 카테고리 → 게시글 최신순 1열 목록**.
- 게시글 45개. 댓글이 0개인 글부터 인기글에 수십~100개가량 달린 글까지 가변적. 대댓글 포함한 수가 목록·상세에서 일치하며, 더 보기로 확인 가능.
- 주요 미식축구 선수는 실명 언급, 마칭밴드는 개인 특징 언급, 제러마이아는 전국적 인지도 반영. 인물의 대사·행동을 캐논으로 확정하는 장면은 넣지 않음.
- 실시간 AI 생성, 실제 게시/댓글 작성은 구현하지 않음. 사전 작성된 허구의 학생 게시글 샘플.

## 열기
압축 풀고 `index.html`을 브라우저에서 열면 됨. 공식 홈페이지 → 상단 학생 포털 로그인 → `newcomer` / `duppy1874` → 받은 쪽지 → 비공식 게시판.

## 파일 구성
- `index.html` : 공식 홈페이지 (가을학기 학사 일정 등 기존 업데이트 유지)
- `portal.html` / `portal.js` / `student.css` : 가상 포털
- `underground.html` / `board.js` : 익명 게시판
- `UWP_school_guide.md` : 학교 설정 마스터 + 변경 이력

## 주의
홈페이지는 UWP만 소개하고 WPSU 별도 홈페이지는 포함하지 않음. 대학 설립연도 1874년, 공식 모토 *Duc in Altum*. 로고·인장 디자인은 2026년 12월 검토 예정이며 미확정. 학생들이 게시판에서 주고받는 소문은 설정집의 확정 사실이 아님.
