# UWP · 더피 단독 대학 소개 홈페이지

`index.html`을 브라우저에서 열면 University of Washington Pacific의 단독 소개 홈페이지가 나와.

- 구성: 학교 소개, 학사 분야, 캠퍼스 개념도, 학생 생활, 역사, 학교 상징/색상
- 반응형 레이아웃, 단과대학 검색, 학교색 HEX 복사
- 외부 폰트·이미지·라이브러리 없이 작동하는 단일 HTML 파일
- WPSU/팩 스테이트의 내용, 학교 전환 기능, 라이벌 비교 페이지는 포함하지 않음
- 확정되지 않은 세부 명칭/시설은 가칭으로 표시함
- 학교 설정 마스터 파일은 홈페이지 공개 배포본과 별도로 보관하면 돼

이 페이지는 2027년 가상의 대학을 소개하는 창작용 페이지로 실존 UW 공식 사이트가 아니야.
