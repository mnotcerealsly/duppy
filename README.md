# UWP 더피 · 스토리 연동 익명 게시판 v5

## 실행

압축을 푼 뒤 `index.html` 열기 → 포털 로그인 → 받은 쪽지 → 익명 게시판.
학생 포털은 아이디 `newcomer`와 비밀번호가 **이미 입력된 상태**로 열립니다. 비밀번호는 브라우저의 `type="password"` 입력 필드로 가려져 표시됩니다. `로그인` 버튼만 누르면 됩니다.
바로 게시판을 열려면 `underground.html`. HTML·CSS·JS는 같은 폴더에 두어야 합니다.

## 구성

- 기존 글 **45개 유지**, 업로드된 9개 설정 파일을 바탕으로 새 게시글 **52개 추가** → 총 **97개**
- 전체 댓글·대댓글 **1170개** (기존 843개 + 추가 327개)
- 다크 게시판 · HOT 3개 · 카테고리 · 최신순 · 본문 검색 · 추천·비추천 · 유동적인 답글 트리
- 2027년 10월 23일 이후에 일어나는 갈라 결과·농구 경기 결과는 아직 게시하지 않음. 2027년 11월 6일 갈라는 사전 안내 및 준비 이야기만 담음.
- 기존 홈페이지·학사 안내·대학 설정 마스터는 그대로 유지. 더피 외 대학 소개 페이지는 없음.

## 창작 및 세계관 경계

- **설정 자료의 [확정] 사건과 인물 정보**를 기준으로 작성했으나, 게시글 자체의 목격 위치·말투·댓글·논쟁·전파 과정은 **가상 학생의 창작 반응**으로, 실제 세계관에서 그대로 발생했다고 확정하지 않습니다.
- '[상상 장면]'이나 미래 갈라·농구 경기의 결말, 인물의 공개되지 않은 가족사·사적 과거는 확정된 사건처럼 노출하지 않았습니다.
- 미식축구 주전들은 유명인, 마칭밴드는 단체는 유명하지만 개인은 덜 알려짐, 테오·에디는 주로 관련 생활권, 제러마이어는 널리 알려짐이라는 기준을 따릅니다.
- 온라인 계정은 가상·오프라인 데모입니다. 실제 신원 확인이나 서버 인증이 없으며 추천·비추천은 해당 브라우저에만 저장됩니다. 실시간 AI 글 생성 기능은 포함되지 않습니다.
- 학생 포털 `DIVE` 이름은 가칭이며 학교 로고·인장은 2026년 12월 디자인 예정 상태입니다.
