# UWP 더피 홈페이지 — 익명 게시판 다크 모드 / 추천·비추천 / 대댓글 편차 v4

## 이번 수정
- **다크 모드**: 공식 홈페이지와 포털은 기존 유지, 익명 게시판만 어두운 차콜·딥틸 테마로 변경.
- **댓글·대댓글 다양화**: 게시글 45개 및 기존 댓글 내용 유지, 일부 답글을 대화 가지로 재구성하고 추가 샘플 반응을 작성. 무플/무답글/1개/다수/깊은 대댓글 혼합.
- **추천/비추천**: 게시글 목록·상세 및 댓글·대댓글의 ▲ 추천 / ▼ 비추천 클릭 가능. 한 항목에 한 방향만 선택되며 다시 누르면 취소. 브라우저 localStorage 저장(허용되지 않으면 현재 화면에서만 유지).
- **인기글 3개 → 카테고리 → 최신순**과 모바일 1열 구성 유지.
- **확정 전공**: 파비안 Interdisciplinary Studies (B.A.), 제러마이아 International Studies (B.A.)를 학교 설정 MD에 반영.

## 열기
압축을 풀고 `index.html`을 열기. 학교 홈페이지 → DIVE(가칭) 포털 → 가상 로그인(`newcomer` / `duppy1874`) → 받은 쪽지 → 비공식 익명 게시판.
게시판만 보려면 `underground.html` 열기. **`board.js`가 같은 폴더에 있어야 작동**.

## 데모 범위
표시되는 게시물과 반응 수치는 미리 생성한 허구의 샘플이며 서버에 접속하지 않는다. 추천·비추천 역시 본인 브라우저에만 반영되고 다른 사용자에게 전달되지 않는다. AI가 접속할 때마다 새 댓글을 실시간 작성하는 기능은 포함하지 않음.
학교 인장은 아직 미정이며 2026년 12월 디자인 예정. 모토는 *Duc in Altum* / 설립은 1874년.
