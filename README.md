# UWP / 더피 — 2027 홈페이지 + 학교 설정집 (수정본)

## 최신 반영
- University of Washington Pacific, 설립연도 **1874년** (2027년 기준 153년 역사). 개교 당시 교명 유지.
- 공식 대학 모토 **Duc in Altum** (깊은 곳으로 나아가라), 누가복음 5:4 유래. 라틴어 원문 보존.
- 한국어 중심 홈페이지; 학교·학과·건물 등의 영문 고유명은 유지.
- 공식 학교색(HEX): Sea Teal #007C83 / Black #171B1C / White #FFFFFF / Silver #C0C7C9(장식색).
- 공식 레터마크/워드마크, 대학 인장, 스포츠 아이덴티티 **디자인 검토는 2026년 12월 예정**. 현재 임시 `UWP` 타이포그래피만 사용하며 로고나 인장이 확정되었다는 뜻이 아님.
- 사이트는 더피(UWP) 단독; WPSU의 독립 홈페이지는 만들지 않음.

## 이번 학사 일정 및 포털 이름 수정
- 공식 홈페이지 상단에 **학사 일정** 메뉴를 추가하고, 기존에 논의한 2027–2028 연간 일정안을 공개 페이지와 학생 포털에 모두 표시한다.
- **확정 일정(가을학기 개강·홈커밍·자선 갈라)**과 **제안안(중간고사·기말고사·휴강·방학·봄학기 개강·학위수여식)**을 구분한다.
- 개교기념일의 **정확한 월일은 미정**이므로 만들어 넣지 않았다.
- `MyUWP` 이름은 사용하지 않는다. 포털 데모에는 **DIVE(가칭)**를 잠정 사용하지만, 최종 명칭은 아직 미확정이다.

## 실행 방법
압축을 해제한 폴더에서 `index.html`을 열면 된다. 외부 의존성 없이 작동하게 제작했다.

1. `index.html`: 학교 공식 홈페이지 스타일의 세계관 소개.
2. 상단 `학생 포털 로그인` → `portal.html`: 가상 신입생 계정 체험.
3. 체험 계정 `newcomer` / `duppy1874`로 로그인.
4. `받은 쪽지` → `비공식 게시판 주소 열기` → `underground.html`.
5. 익명 게시판에 준비된 게시글 30개와 댓글을 읽을 수 있다. 접속마다 순서가 섞인다.

## 구현 범위 / 제한
- **실제 로그인 인증 기능 없음**. 체험용 테스트 계정과 브라우저 세션 연출만 사용함. 개인 정보를 입력하지 말 것.
- **AI 실시간 게시글·댓글 생성 없음**. 게시글과 댓글은 사전 작성한 창작 데이터이며 방문 때마다 순서를 바꾸어 표시할 뿐이다.
- 데이터베이스, 실사용 게시판 글 작성, 실제 메시지 전송, 입학 신청, 실제 서버 저장은 구현하지 않았다.
- 학교 시설명, 단과대학 구성 등 아직 최종 결정되지 않은 일부 내용은 설정집과 사이트에서 **구성안/가칭**으로 다뤘다.
- 대략적 캠퍼스 안내도는 정확한 지리적 실측도가 아니다.
- 게시판의 가상 학생 발언은 대학의 확정된 사실이나 공식 입장이 아니다.
- 사이트는 실존 University of Washington의 공식 사이트가 아니며 2027년 가상 세계관을 위한 창작물이다.
